# Тест-план: «Звёздная карта — глубокий космос»

Требования заказчика → как проверяется → где тест.

| # | Требование | Проверка | Тест |
|---|-----------|----------|------|
| R1 | Хэдера нет совсем | нет `<header>`, роли `banner`, навигации | components/page, e2e/layout |
| R2 | Раздела «Подарки» нет, фразы «Ждём вместо цветов…» нет | нет `#gifts`, нет текста «подарк», «вместо цветов» | components/page, e2e/layout |
| R3 | Раздела «вторая половинка» нет | нет радио-кнопок и текста | components/RsvpForm, api |
| R4 | «Дмитрий» не вылезает за экран слева (и никакое имя — ни слева, ни справа) | bbox каждого имени внутри окна на 11 ширинах 280–1920 px, до и после анимации | e2e/responsive |
| R5 | Полный адаптив, особенно маленькие телефоны | нет горизонтальной прокрутки на 280/320/360/375/390/414/768/1024/1280/1440/1920; карта неба, форма, кнопка — в пределах экрана | e2e/responsive |
| R6 | Удобство на телефоне | цели касания ≥ 44 px, шрифт полей ≥ 16 px (iOS не зумит) | e2e/responsive |
| R7 | Анимации Motion, уважение к «уменьшить движение» | при `prefers-reduced-motion: reduce` весь контент видим сразу (opacity 1) | e2e/motion |
| R8 | Форма работает | ошибки, фокус на первом ошибочном поле, «Свой вариант», отправка, экран «Спасибо» | components/RsvpForm, e2e/flow |
| R9 | Админка работает без «второй половинки» | вход по паролю, ответ виден, выгрузка xlsx | api, e2e/flow |
| R10 | Доступность | axe: нет нарушений уровня serious/critical | e2e/a11y |
| R11 | Без ошибок в консоли | ни одной console.error / pageerror | e2e/layout |
| R12 | Дизайн-токены | нет сырых цветов в components/ и app/ (кроме tokens.css) | unit/design-tokens |

Порядок работы: тест пишется до кода → прогон (красный) → код → прогон (зелёный) →
полная проверка: typecheck → unit/компоненты → production-сборка → e2e на реальном Chromium.
